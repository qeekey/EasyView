# EasyView（简图）

EasyView 是一款原生 macOS 看图应用。它将常用位置、图片浏览与单张图片信息放在同一窗口中，并提供沉浸式大图查看器，适合快速翻阅本地图片文件夹。

## 功能

### 打开与浏览

- 打开任意图片文件夹；首次启动时自动载入系统“图片”目录。
- 从“文件 → 打开图片…”一次选择多张图片，或将图片、文件夹拖入窗口。
- 支持从 Finder 直接用本应用打开图片：会自动切换到该图片所在文件夹并进入大图查看。
- 侧边栏可快速打开“图片”“桌面”“下载”，也可选择其他文件夹。
- 可选递归显示子目录中的图片；该偏好会在之后启动应用时保留。
- 支持 JPG、JPEG、PNG、GIF、HEIC、HEIF、TIFF、BMP、WebP。

### 图片列表

- 在自适应缩略图网格与详细列表之间切换。
- 用底部滑杆调整缩略图大小；可在选项中隐藏缩略图文件名。
- 按文件名搜索，并可在选项中关闭搜索栏。
- 按名称、类型、修改日期、文件大小或像素尺寸排序，并支持升序、降序。
- 列表视图显示缩略图、名称、类型、尺寸、大小与修改日期；点击列标题排序，拖动列标题右侧分隔线可调整列宽。
- 单击选择图片，双击进入大图；状态栏会显示当前文件夹与筛选后的图片数量。
- 右侧“简介”抽屉展示当前图片的预览、格式、像素尺寸、文件大小、修改时间和所在位置。

### 大图查看

- 暗色沉浸式背景下查看原始图片。
- 可显示或隐藏文件名、像素尺寸和文件大小。
- 支持上一张、下一张、缩小、放大、适合窗口、向左/向右旋转。
- 工具栏的废纸篓按钮会将当前图片移到 macOS 废纸篓，并继续显示相邻图片。
- 放大后可拖动平移图片，浏览超出视区的部分；缩放范围为 100%–800%。
- 按 `Esc`、空格或“返回浏览”回到图片浏览界面。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘O` | 打开文件夹 |
| `⇧⌘O` | 打开一张或多张图片 |
| `⌘I` | 打开/关闭右侧简介抽屉 |
| `Space` | 进入或退出大图查看 |
| `←` / `→` | 选择上一张/下一张图片；在大图中切换图片 |
| `Esc` | 退出大图查看 |

## 运行

**要求：** macOS 13（Ventura）或更新版本，以及可用的 Swift 工具链。项目基于 Swift Package Manager，不需要额外第三方依赖。

在项目根目录运行：

```bash
./scripts/run.sh
```

该命令会构建应用并打开 `dist/简图.app`。

## 构建分发包

只构建可运行的应用包：

```bash
./scripts/build-app.sh
```

产物为 `dist/简图.app`。构建脚本会以 release 配置编译，并为本机运行进行临时签名。应用未使用 Apple Developer 证书签名；首次将其分发到其他电脑时，可能需要在“系统设置 → 隐私与安全性”中确认打开。

## 项目结构

```text
Sources/EasyView/
├── EasyViewApp.swift      # 应用入口、菜单与全局快捷键
├── ContentView.swift      # 主窗口、工具栏、拖放与全屏状态同步
├── BrowserViews.swift     # 侧边栏、缩略图/列表、简介抽屉
├── ImageViewer.swift      # 沉浸式大图查看与键盘操作
└── Models.swift           # 图片扫描、筛选、排序与缩略图缓存
Resources/                 # 应用图标与 Info.plist
scripts/                   # 启动与打包脚本
```
