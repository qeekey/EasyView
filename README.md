# EasyView（简图）

EasyView 是一款原生 macOS 看图应用。它将常用位置、图片浏览与单张图片信息放在同一窗口中，并提供沉浸式大图查看器，适合快速翻阅本地图片文件夹。

## 功能

### 浏览

- 默认打开“图片”目录；也可从侧边栏、Finder、文件菜单或拖放打开图片和文件夹。
- 提供缩略图和列表模式、文件名搜索、排序、目录前进/后退及右侧“简介”抽屉。
- 可选择显示子目录；子目录中的图片不会混入当前目录。单击选中，双击文件夹进入、双击图片预览。
- 支持 JPG、PNG、GIF、HEIC、TIFF、BMP、WebP 等常见格式。

### 查看图片

- 大图模式支持翻页、缩放和平移、旋转、适合窗口及自动播放。
- 全屏模式隐藏控制栏，让完整图片按比例适合屏幕；按 `Esc` 返回进入全屏前的界面。
- 删除图片会移到 macOS 废纸篓，并继续显示下一张可用图片。

### 应用更新

- “关于简图”会检查 GitHub Releases；有新版时可下载并安装 `EasyView.dmg`。
- 更新前会校验下载文件和应用版本；校验失败时不会替换当前应用。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘O` | 打开文件夹 |
| `⇧⌘O` | 打开一张或多张图片 |
| `⌘I` | 打开/关闭右侧简介抽屉 |
| `Space` | 缩略图或列表中预览选中图片、进入选中文件夹；大图中查看下一张图片 |
| `←` / `↑` | 列表和大图中查看上一张图片；缩略图中选中相应方向的项目 |
| `→` / `↓` | 列表和大图中查看下一张图片；缩略图中选中相应方向的项目 |
| `Esc` | 全屏时返回原界面；普通大图时返回浏览 |

## 运行

**要求：** macOS 13 或更新版本，以及 Swift 工具链；无需第三方依赖。

在项目根目录运行：

```bash
./scripts/run.sh
```

该命令会构建应用并打开 `dist/简图.app`。

## 构建分发包

只构建可运行的应用包：

```bash
./scripts/build-app.sh
```

产物为 `dist/简图.app`。版本号取自当前分支可达的最新 Git tag；构建脚本会进行本机临时签名。分发给其他用户时，建议使用 Apple Developer 证书签名并公证。

## 项目结构

```text
Sources/EasyView/
├── EasyViewApp.swift      # 应用入口、菜单与全局快捷键
├── ContentView.swift      # 主窗口、工具栏、拖放与全屏状态同步
├── BrowserViews.swift     # 侧边栏、缩略图/列表、简介抽屉
├── ImageViewer.swift      # 沉浸式大图查看与键盘操作
└── Models.swift           # 图片扫描、筛选、排序与缩略图缓存
Resources/                 # 应用图标与 Info.plist
scripts/                   # 启动与打包脚本
```
