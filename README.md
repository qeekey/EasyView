# EasyView（简图）

EasyView 是一款原生 macOS 看图应用。它将常用位置、图片浏览与单张图片信息放在同一窗口中，并提供沉浸式大图查看器，适合快速翻阅本地图片文件夹。

## 功能

### 打开与浏览

- 打开任意图片文件夹；首次启动时自动载入系统“图片”目录。
- 从“文件 → 打开图片…”一次选择多张图片，或将图片、文件夹拖入窗口。
- 支持从 Finder 直接用本应用打开图片：会自动切换到该图片所在文件夹并进入大图查看。
- 侧边栏可快速打开“图片”“桌面”“下载”和当前用户主目录（房屋图标旁显示用户名），也可选择其他文件夹。
- 顶部显示当前目录名，并提供目录浏览的后退、前进按钮。
- “选项 → 显示子目录”可控制是否显示当前目录下的文件夹；子目录中的图片不会与当前目录的图片混在一起，需进入该文件夹后查看。此选项会在之后启动应用时保留。
- 支持 JPG、JPEG、PNG、GIF、HEIC、HEIF、TIFF、BMP、WebP。

### 图片列表

- 在自适应缩略图网格与详细列表之间切换。
- 用底部滑杆调整缩略图大小；可在选项中隐藏缩略图文件名。
- 按文件名搜索，并可在选项中关闭搜索栏。
- 图片和显示出的文件夹都参与名称、类型、修改日期、文件大小与像素尺寸排序；支持升序、降序。文件夹按大小和尺寸排序时以 `0` 计算，在列表中显示为 `--`。
- 列表视图将小缩略图或文件夹图标与名称放在同一列，另外显示类型、尺寸、大小和修改日期。列标题均左对齐，只有“大小”列的内容右对齐；点击列标题排序，拖动标题右侧分隔线可调整列宽。
- 调整窗口宽度时，“名称”列随之伸缩，其他列保持宽度；窗口不能缩到启动尺寸以下。
- 单击图片或文件夹仅选中；双击图片进入大图，双击文件夹进入该目录。进入目录后默认选中第一张图片。状态栏显示当前路径和筛选后的项目数。
- 右侧“简介”抽屉展示选中图片或文件夹的预览、类型、尺寸、大小、修改时间和所在位置。

### 大图查看

- 暗色沉浸式背景下查看原始图片。
- 可显示或隐藏文件名；图片的像素尺寸和文件大小可在“简介”抽屉中查看。
- 支持上一张、下一张、缩小、放大、适合窗口、向左/向右旋转，以及按设置的间隔自动播放。
- 工具栏的废纸篓按钮会将当前图片移到 macOS 废纸篓，然后跳过后续目录，显示下一张图片；后面没有图片时显示前一张，没有图片可显示时返回浏览界面。
- 放大后可拖动平移图片，浏览超出视区的部分；缩放范围为 100%–800%。
- 按 `Esc` 或“返回浏览”回到图片浏览界面。

### 应用更新

- 打开“关于简图”时会检查 GitHub Releases。发现比当前版本更新且带有 `EasyView.dmg` 的发行版时，在版本号下方显示“立即更新到最新版”；当前版本已是最新版本时不显示按钮。
- 点击按钮后会下载 DMG、校验 GitHub 提供的 SHA-256，并检查其中的应用版本和标识。准备完成后应用会关闭，由安装步骤替换当前应用并重新打开；若应用安装在受保护的位置，macOS 会请求管理员授权。
- 若 Release 标签版本与 DMG 内嵌版本不一致，更新会安全中止并提示冲突，不会用旧版覆盖当前应用；发布 DMG 时需通过 `scripts/build-app.sh` 从对应 tag 构建。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘O` | 打开文件夹 |
| `⇧⌘O` | 打开一张或多张图片 |
| `⌘I` | 打开/关闭右侧简介抽屉 |
| `Space` | 缩略图或列表中预览选中图片、进入选中文件夹；大图中查看下一张图片 |
| `←` / `↑` | 列表和大图中查看上一张图片；缩略图中选中相应方向的项目 |
| `→` / `↓` | 列表和大图中查看下一张图片；缩略图中选中相应方向的项目 |
| `Esc` | 退出大图查看 |

## 运行

**要求：** macOS 13（Ventura）或更新版本，以及可用的 Swift 工具链。项目基于 Swift Package Manager，不需要额外第三方依赖。

在项目根目录运行：

```bash
./scripts/run.sh
```

该命令会构建应用并打开 `dist/简图.app`。

## 构建分发包

只构建可运行的应用包：

```bash
./scripts/build-app.sh
```

产物为 `dist/简图.app`。构建脚本会读取当前分支上可从 HEAD 到达的最新 Git tag，并将其写入应用版本信息；“关于简图”显示该 tag。若当前分支没有可达 tag，构建会提示先创建 tag。脚本以 release 配置编译，并为本机运行进行临时签名。应用未使用 Apple Developer 证书签名；首次将其分发到其他电脑时，可能需要在“系统设置 → 隐私与安全性”中确认打开。

## 项目结构

```text
Sources/EasyView/
├── EasyViewApp.swift      # 应用入口、菜单与全局快捷键
├── ContentView.swift      # 主窗口、工具栏、拖放与全屏状态同步
├── BrowserViews.swift     # 侧边栏、缩略图/列表、简介抽屉
├── ImageViewer.swift      # 沉浸式大图查看与键盘操作
└── Models.swift           # 图片扫描、筛选、排序与缩略图缓存
Resources/                 # 应用图标与 Info.plist
scripts/                   # 启动与打包脚本
```
